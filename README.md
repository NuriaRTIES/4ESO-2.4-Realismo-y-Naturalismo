# Realismo y Naturalismo — Literatura del Siglo XIX (4º ESO)

Presentación web interactiva y dinámica diseñada para el alumnado de **4º de ESO** de Lengua Castellana y Literatura (IES Torre del Rei).

## 🚀 Despliegue en GitHub Pages

Para publicar y ver esta presentación online de forma gratuita con **GitHub Pages**:

1. Sube este repositorio a tu cuenta de GitHub.
2. Entra en el repositorio en GitHub y ve a la pestaña **Settings** (Configuración).
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: Selecciona `main` (o `master`) y la carpeta `/ (root)`.
   - Pulsa **Save**.
5. En 1-2 minutos, GitHub te proporcionará el enlace público (por ejemplo: `https://tu-usuario.github.io/tu-repositorio/`).

## ✨ Características de la Presentación

- **24 diapositivas estructuradas**: Cubren el contexto histórico del siglo XIX en España, el paso del Romanticismo al Realismo y Naturalismo, las características de ambos movimientos, la novela de Benito Pérez Galdós (tres épocas y ruta literaria), Emilia Pardo Bazán y Leopoldo Alas "Clarín".
- **Interactividad y navegación ágil**:
  - Navegación con teclado: Flechas `←` / `→` o barra `Espacio`.
  - Botones táctiles y barra de progreso fluida.
  - Menú lateral de **Índice desplegable** con acceso directo a cualquier diapositiva.
- **Modo pantalla completa**:
  - Botón de pantalla completa global para proyección en clase.
  - Visor modal (*lightbox*) para ampliar cualquier imagen a pantalla completa con un solo clic.
  - Reproductores de vídeo integrados para fragmentos de adaptaciones literarias (*Los pazos de Ulloa* y *La Regenta*).
- **Actividades conectadas**:
  - Diapositivas de actividades vinculadas al libro de texto y al dossier de trabajo en la plataforma educativa **Aules**.
  - Ilustración temática del cuaderno y bolígrafo en las actividades.
  - Tabla comparativa de la novela naturalista optimizada con desplazamiento vertical adaptativo.
